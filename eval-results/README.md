# M4 snapshot

`m4-results.json` is the result file committed with milestone M4 (B0, B1 and A1 per scenario). It has not been regenerated since, and the simulator has been fixed and extended in M5 and M6, so **do not read current numbers from it**.

Current results, including the current M4 comparison, the full ablation table, and the real-data and model results, are in [`backend/eval-results/`](../backend/eval-results/README.md), with the commands that reproduce them. The backend API (`/api/eval`) and CI read that directory.
